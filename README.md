# Acavelliê | Moda Modesta

Portfólio estático feito com HTML, CSS e JavaScript, sem backend.

## Como abrir

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Como trocar os links

No `index.html`, procure o comentário `LINKS DE REDIRECIONAMENTO` e substitua os endereços `href` de WhatsApp e do grupo VIP pelos links reais. Para o WhatsApp, use o formato `https://wa.me/55DDDNUMERO`. Os links de e-mail, TikTok e Instagram também podem ser alterados na navegação social, no início do arquivo.

As imagens das logos ficam na pasta `assets/`. O botão com três pontos em cada cartão compartilha o endereço do link ou copia o endereço para a área de transferência, dependendo do navegador.
